# Design system

Three token layers in `src/lib/design/tokens/`: **primitives** (raw ramps — navy, parchment, gold,
laurel, amber, oxblood, graphite; space on a 4 px base; radii 2/4/6 px; motion), **semantic** (surface,
ink, rule, accent, state — per theme), **component** (button, field, ledger, sheet, rail, seal, QR,
skeleton). Components read only semantic and component tokens. A Night Ink section inside a light page
uses the `.night` scope, which re-declares both layers.

## Type

Manrope variable (200–800), self-hosted: Latin preloaded (24 KB), Latin Extended on demand; metric-matched
fallback for zero layout shift. Roles: `--type-denomination` (hero balance, weight 300, −0.035em),
display, title, body (450), data (14 px, tabular, slashed zero), eyebrow (11 px, 700, 0.14em, uppercase),
micro. Every amount, height, nonce, slot and identifier uses tabular lining numerals. Balances: integer
large, separator and fraction at 55 % in a lighter weight; "Significant" hides trailing zeros only.

## Layout

Desktop: 280 px ledger rail + content to 1280 px. ≤ 1100 px: the rail becomes a drawer behind an
identity strip. ≤ 720 px: a bottom action bar (Send, Receive, Activity, Lock). Rows 56 px (64 px on touch);
targets ≥ 24 px, 44 px on coarse pointers.
