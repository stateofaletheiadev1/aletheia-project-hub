# DDR-0003: AEY and ALnT roundels

Numismatic marks drawn for the wallet. AEY, the money of account: a gold beaded rim and a rosette ring, as
on a coin. ALnT, the network's utility asset: a graphite rim with an octagonal inner frame, as on a token.
Both carry the asset code in Manrope 700; neither imitates an existing currency symbol.
