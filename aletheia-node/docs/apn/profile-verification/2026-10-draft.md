# Rail profile verification record: drafts of 2026-10-08

Spec Section 40C.3 requires every active profile to be checked by two reviewers against the
scheme operator's current publications and the partner's implementation guide, with the check
recorded here. This record states where each profile stands. None has been reviewed yet, so
all seven are `draft`: the gateway refuses to load them in production (`ProfileSet::load` with
`active_only`), and only the rail simulator and tests use them.

| Profile | File | Status | Values left for verification |
| --- | --- | --- | --- |
| SEPA Credit Transfer | `crates/rails/profiles/sepa-sct/2025.toml` | draft | message versions, return and recall windows, TARGET calendar data |
| SEPA Instant | `crates/rails/profiles/sepa-sct-inst/2025.toml` | draft | message versions, scheme time-out, return and recall windows |
| SEPA Direct Debit Core | `crates/rails/profiles/sepa-sdd-core/2025.toml` | draft | message versions, return window, refund periods |
| SEPA Direct Debit B2B | `crates/rails/profiles/sepa-sdd-b2b/2025.toml` | draft | message versions, return window |
| SWIFT CBPR+ | `crates/rails/profiles/swift-cbpr-plus/2025.toml` | draft | currencies and calendar of the chosen correspondent, character set (drafted narrow), BAH version |
| Fedwire Funds | `crates/rails/profiles/fedwire/2025.toml` | draft | message versions, operating hours and cut-offs, character set (drafted narrow) |
| FedNow | `crates/rails/profiles/fednow/2025.toml` | draft | network limit, scheme time-out, return windows, character set (drafted narrow) |

Where a value was uncertain when drafted, the profile leaves it empty or chooses the narrower
rule (a character set that always passes, a required field), so a draft refuses payments it
might mishandle rather than sending them.

To activate a profile, two different reviewers check every value, set `status = "active"`,
fill `reviewed_by` and `reviewed_on`, and add a row to a new record in this folder naming the
release.
